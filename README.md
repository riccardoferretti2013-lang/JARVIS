# Project J.A.R.V.I.S.

## Descrizione

J.A.R.V.I.S. è un assistente AI personale sviluppato in Python.

L'obiettivo del progetto è creare un sistema modulare capace di automatizzare attività,
gestire informazioni e interagire con l'utente attraverso diversi strumenti.

Fase attuale: Setup iniziale
